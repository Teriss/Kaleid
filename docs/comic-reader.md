# 本地漫画

支持图片目录、CBZ/ZIP、CBR/RAR（含 RAR5）、7z/CB7。每个图片目录或压缩包是一章，包内子目录按完整路径自然排序，不会拆成多个章节。过滤隐藏图片和 `__MACOSX` 文件。PDF、在线源、加密和分卷压缩包暂不支持。

## 阅读

漫画阅读器独立于图片和小说。顶部提供章节、缩略图、书签、设置及全屏；底部提供章切换、页码、进度条和缩放。工具栏在停止操作三秒后隐藏，移动鼠标或聚焦控件重新显示，侧栏打开时保持显示。

- 单页、双页、纵向条漫；方向和模式的最近选择用于新漫画，作品自己的设置优先。
- 双页默认封面单独显示，可调整配对；横向跨页图片独立显示。
- 适应窗口、适应宽度、原始尺寸；条漫的适应窗口会同时约束单张图片的宽高，适应宽度则按窗口宽度连续滚动。Ctrl＋滚轮缩放，双击放大／还原，放大后拖动。方向键／PageUp／PageDown／空格翻页，Home／End 跳首尾，F 全屏，Esc 先关闭侧栏、还原缩放，再返回媒体库。
- 条漫保存页面文件名与页内相对位置；图片加载、窗口变化及重启后按该位置恢复。文件增删后优先匹配原页面名，不存在时回退到有效页码。
- 越过章末才标为读完。同一作品内继续翻页／向下滚动会接续下一章；仅预加载或跳到末页不会标记已读。最后一章继续翻页显示作品结束提示。
- 缩略图和条漫均按窗口渲染；当前页面前一页、后三页预取，后台预取最多两个并发。显示、缩略图和预取共享章节图片缓存，返回已加载页面直接复用；缓存按压缩数据与解码尺寸估算，以 128 MiB 为淘汰目标，正在显示的页面受保护，离开章节释放。坏页可以重试或继续翻页跳过。

## 作品与章节

漫画导航中的“漫画作品与章节”打开整理面板，也可从单项右键菜单或阅读器进入。作品列表提供继续阅读；“本地漫画”可按未读、阅读中、已读筛选，并手动标记状态。标为未读会重置该章阅读位置。

识别 `ComicInfo.xml` 中的 Series、Title、Number、Volume、Writer、Summary 和 FrontCover 页。相同来源根目录内的明确系列元数据自动归组；同目录无元数据的多章只进入“待整理”，需要手动确认。可以新建作品，跨目录勾选已有章节，改作品名称，拖动或用上下按钮排序。

保存分组会把所选章节从原作品移入当前作品；删除分组或移除章节不会删文件、收藏或书签。手动解除的分组不会在后续扫描时被自动重新创建。所有操作只改应用数据库，原媒体 ID 保留，同类型库仍共享收藏和进度。

## 格式实现与数据

ZIP 使用缓存的中央目录条目直接读取；RAR/7z 使用随应用附带的完整 7-Zip 26.04，不依赖系统安装。运行开发和生产构建时自动执行 `npm run comic:prepare`，首次下载固定官方版本，校验压缩包和各文件 SHA-256，之后离线复用。安装包附带 `comic-runtime/7z.exe`、`7z.dll`、许可和版本清单。

普通压缩包页面按需缓存，固实压缩包合并为一次后台解压任务。重复页面请求合并，离开章节取消解压任务；会话标识防止旧阅读器关闭时取消新会话。磁盘缓存以 2 GiB 为淘汰目标，当前正在读取／解压的目录受保护，单包最多 4 GiB、单条目最多 128 MiB、最多 20,000 条目；当前大包可暂时超出淘汰目标。设置中的清理缓存会释放索引并移除漫画缓存。

作品、章节关系和书签存在 SQLite；独立阅读偏好也存入数据库。升级首次创建漫画表前，对已有数据执行一致性备份到 `backups/pre-comic-*.sqlite`。原页码进度、文件路径、收藏不要求重新导入；后台扫描会补齐旧漫画元数据。

## 验证

```powershell
npm run comic:prepare
npm run test:comic
npm run build
npm run test:comic:reader
```

单元／集成测试生成 ZIP、RAR4、RAR5、固实 7z、加密包、坏包与路径样本，验证配对、千页虚拟窗口、稳定页名恢复和数据库迁移。Electron 测试使用独立临时媒体库及用户目录，验证真实缩放、长图重启续读、书签、连续翻章、作品保存和小说回归，并输出截图到 `artifacts/`。

安装目录验证可设置 `KALEID_COMIC_EXE` 指向构建的 Kaleid.exe 后执行同一脚本。测试不会使用正常用户的媒体库或阅读数据。
