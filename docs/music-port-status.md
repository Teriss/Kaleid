# 音乐移植预览状态

基准：Folia `26c57f9b1b26b402a09e8943171a332215418ce6`（上游 package.json 为 0.7.21）。Kaleid 本次为 **0.4.0-preview.5**。这是可运行的阶段性预览，**完整音乐子系统移植尚未完成**。

## 已连接的能力

- 本地／在线／Navidrome 显式入口；六个平台直接使用固定版本的 provider registry、规范化和后台桥接，不启动 Folia 首页或主进程。
- 平台歌曲搜索、推荐集合、账号入口、用户歌单和收藏专辑；按实际方法能力显示每日推荐、电台与创建歌单入口。
- 歌单／专辑／歌手歌曲查询；歌曲详情的艺术家和专辑可导航到对应集合。
- 本地、在线、Navidrome 的身份分离；远程曲目保存在独立 music.sqlite，元数据按页加载；六种布局使用同一分页源。
- 单个音频输出播放器；胶囊、播放页、墙面、桌面歌词和迷你窗口共用状态。辅助窗口不创建音频元素。视频播放继续暂停本应用音乐。
- 完整范围队列、应用本地歌单、播放会话及暂停恢复；旧 library.sqlite 在迁移前通过 SQLite VACUUM INTO 一致性备份到 userData/backups。
- 原有本地歌词解析与资料确认流程保留；在线歌词采用上游结构化结果。没有逐字时间的数据按行呈现。
- 固定版本全部 14 个歌词 renderer 和动态背景注册表已接入；主题颜色可改；AI 主题使用上游提示词、JSON 客户端及清洗器，用户密钥在后台加密保存。
- 十段均衡器、原有响度统一、睡眠定时、输出设备和媒体键保留；上游九项附加音效已接到同一 Web Audio 图。
- 凭据不进入导航记录；平台 HTTP 采用固定路由，歌词代理采用固定域名。音频和封面通过后台分配的资源标识读取。
- 五类媒体独立的会话历史记录目录、查看器、播放详情、浮层、设置分区、搜索提交、布局、排序；位置变化只更新快照。关闭内容跳回父浏览页，历史恢复不自动播放视频或音乐。
- 五类页签恢复各自浏览页；多库列表只列当前类型，零库保留创建入口和音乐在线入口。

## 尚未接通，不能当作已完成

- Folia 双音轨播放引擎、无缝播放、交叉淡化、自动混音／分轨／拍点分析。当前仍由 Kaleid 的单音频播放器输出；模型下载和完整性校验已提供，模型推理链路尚未接入。
- 外部 Now Playing 来源与状态时钟。
- Folium 安装、启停、权限、运行时事件与音乐注册点。上游源码已固定保留，主应用未启动这些服务。
- 主题样式的完整调参／预设管理与 AI 分词编辑，后台音乐缓存完整策略，平台歌单歌曲的增删／排序和集合订阅等剩余写操作。
- 本地和远程收藏／最近打开已能一起浏览，但当前组合排序为本地分页后远程分页，尚非跨来源的全局时间排序。
- 所有平台的真实登录、会员音质、过期授权、账户写操作，以及真实 Navidrome 服务仍需应用内授权／服务验证。不能以适配器存在认定真实账号场景通过。
- 逐一视觉验证全部 14 个动画样式、跨平台原生模块的完整验收尚未完成。当前有 Luminous 的真实绘制截图和像素区域检查。
