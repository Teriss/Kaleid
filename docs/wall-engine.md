# Folia 墙面重构

以仓库内 Folia 固定提交 `26c57f9b1b26b402a09e8943171a332215418ce6` 为基准，适配 Kaleid 的媒体身份、分页来源和导航历史，不启动上游应用入口或播放状态。

## 行为与结构

- 使用上游 12×8 块、每块 12 个格位、128 格子和 8 间距；模板变体、聚焦重排和无限墙起始偏移直接来自上游纯函数。默认缩放按视口取 52%、64%、76%，手动缩放按浏览范围保留。
- 相机和开口动画直接写左右世界层的 transform。平移按设备像素对齐；React 只在接近已渲染边缘、内容变化、聚焦变化或运动落定时更新，不再承担逐帧相机状态。
- 滚轮判别、增量归一化和平滑步进直接复用上游；触控板直接跟手，鼠标滚轮累积位移，手势经过中央导航时保持锁定，移动光标或手势结束后释放。拖动采用上游惯性参数，有限墙增加拖动阻尼与松手回弹。
- 目录切换先保留旧墙，等待目标可见分页，再统一规划整墙翻面。格位身份稳定，在侧立时换内容；完成信号来自磁贴动画，按规划时长设置兜底。同一墙面切换栏目、集合和历史时保留当前相机、缩放与开口锚点，只替换卡片；首次进入恢复浏览记忆。异步提交和动画完成都有令牌保护。
- 空目录结束转场后显示空状态，不再被墙面原有的空目录回退逻辑自动送回父级；其他布局保留原行为。加载、未登录、空数据和失败均保留墙面，在菜单左右显示同一提示；失败在当前来源重试，不退回上一页。
- 中央导航提供 120 DIP 紧凑菜单、300 DIP 手动展开、360 DIP 搜索和隐藏状态，小窗口按可用宽度限制；状态在同一墙面跨目录沿用。搜索关闭恢复此前的菜单与相机，菜单拖出横向视口后在运动停止时收起，通过边缘入口在当前位置唤回。内容翻转、宽度开合、两侧墙让位共同编排，快速反向操作会取消旧动画并恢复交互。
- 五类媒体统一使用中央导航，连接现有来源、目录路径、搜索、排序操作；本地首次隐藏、在线紧凑显示，搜索自动展开。同一墙面切换内容保留相机与菜单状态；降低动态效果时使用淡出／淡入。

## 兼容

`BrowseMemory` 增加墙布局版本、手动缩放标记、起始格位和键盘焦点。旧模板的空间坐标在首次进入时失效，媒体焦点与有限／无限偏好保留，并在新模板中重新定位。新增字段只影响渲染器浏览记忆，不涉及 SQLite 或主进程 IPC。

位置在运动落定、导航快照、失焦及卸载时提交。导航快照通过内部 `wall:flush` 事件同步取得相机，不依赖逐帧持久化。

开发构建使用 `npm run build`，Windows x64 安装包使用 `npm run dist`。生成的安装包、源码归档和运行产物只保留在本地，不纳入版本管理。
