# 导航、阅读背景与音乐墙面

漫画、图片和小说覆盖阅读时，底下的网格和画廊停止交互、滚动及浏览位置写入；滚动条保留占位。条漫和阅读侧栏保持独立滚动，退出恢复打开前的列表位置。

五类媒体分别维护会话历史。目录、栏目、歌单／专辑、独立搜索结果和媒体详情是目的地；排序、布局、即时过滤、菜单、设置、账号、队列、播放操作和视频小窗／全屏属于当前界面的状态。后者不会新增历史或清空前进记录。返回历史时保留各视图最新排序和布局，Esc 先关闭当前临时浮层。

## 五类媒体的墙面菜单

图片、音乐、视频、小说和漫画的墙面共用中央菜单；其他布局保留原导航。本地墙面首次进入时菜单隐藏，在线音乐默认紧凑菜单。紧凑菜单宽 120 DIP，手动展开 300 DIP，搜索展开 360 DIP；小窗口按可用宽度限制。进入目录、歌单、专辑、栏目及前进／后退时保留当前相机、菜单位置、缩放和宽度，仅变化卡片原地翻转。

拖动或惯性结束后，中央菜单完全离开横向视口就收起，通过边缘入口在当前位置唤回；拖回原位置不会自行展开。菜单、搜索和展开状态不写入导航历史。加载中、未登录、空数据、过滤零结果和请求失败均保留原墙面及菜单，在菜单两侧显示相同提示；登录和重试沿用当前来源。

Ctrl+F / Ctrl+K 或菜单搜索按钮均展开并唤回菜单，聚焦可见输入框；关闭搜索恢复之前的菜单状态。搜索分别保存过滤和提交搜索草稿：

- **过滤当前视图**：实时匹配全部已加载缓存卡片，包含屏幕外卡片；按名称、歌手、专辑和漫画作品信息匹配，空格分词后全部匹配，忽略大小写。中文组词结束后生效。显示匹配数和已加载范围，不补抓数据，也不改变播放队列。保留媒体 ID 和原始索引，播放、收藏及右键操作仍对应原媒体。
- **搜索当前媒体库**：本地来源提交后查询当前库全部已索引媒体，进入独立搜索目的地，不受当前目录或已缓存页限制。
- **搜索在线平台**：在线音乐输入时不请求数据，提交后进入独立搜索结果页；后退可回到原集合。

关闭搜索后过滤标记及清除入口继续可用；清空过滤恢复之前的位置，切换视图清除过滤。输入框内 Esc 先清空过滤，再关闭搜索；其他菜单控件上 Esc 直接关闭搜索。

## 单媒体集合

主动点击文件夹、歌单或专辑等集合时，实际只有一个媒体就直接打开它，关闭／后退返回原列表，不记录中间集合页。单媒体嵌套目录同样跳过，杂项文件不计入媒体数；多媒体、空集合及仅加载部分内容仍正常进入集合。在线按实际接口总数和内容判断，本地按索引验证。单曲集合播放队列只含该曲，不混入父列表的其他媒体；过期的打开请求不会覆盖后续导航。

## 音乐账号和喜欢入口

本地与在线使用独立的切换状态和界面：本地墙面使用本地目录、收藏、最近及搜索，不显示在线推荐栏目和平台账号；无本地库时只保留本地／在线切换及创建入口。在线墙面保留平台栏目及账号。切换来源恢复各自视口，在线页签之间保持菜单位置与缩放。未登录时仍显示中央菜单和两侧登录提示，切换到未登录栏目可唤回此前隐藏的菜单。

在线平台仅启用网易云、QQ 音乐和 YouTube Music；没有 Navidrome 入口。保留停用平台的凭据、收藏和服务器配置，不删除历史数据；旧在线来源恢复至网易云，旧 Navidrome 页面恢复至本地音乐，停用来源队列项跳过并提示。停用平台不初始化后台桥接。

头像打开三平台账号面板，选择平台只查看账号，点击“使用此平台”才切换来源。同一平台仍保存一份账号，沿用已有登录、退出及凭据管理。菜单、列表和详情使用统一账号图组件，通过受控音乐资源协议代理平台 HTTP／HTTPS 头像；失败显示昵称首字或默认图标，过期请求不覆盖新账号。

头像附近的“我喜欢的音乐”在在线来源进入当前账号适配器标记的喜欢歌单，并校验归属，不通过名称猜测；本地来源进入本地音乐收藏。未登录时保留墙面及左右登录提示。真实账号、地区网络、会员权限和授权写操作仍需实际账号验证。

## 回归命令与范围

- `npm run test:navigation`：目的地判定、显示偏好和临时状态不破坏前进、五类历史隔离及目录边界。
- `npm run test:music:filter`：跨缓存分页、屏幕外匹配、媒体身份、原始索引、未加载范围不补抓。
- `npm run test:interactions`：真实 Electron 网格中部阅读后位置恢复、条漫滚动、排序与设置后的前进、中文组词、过滤与零结果、快速输入、翻转和焦点、收藏、账号查看、搜索草稿和显式提交。
- `npm run test:collections`：五类媒体的单媒体嵌套目录直开、返回、多个媒体仍进入目录及单曲队列隔离。
- `npm run test:music:sources`：未登录启动、认证栏目几何位置、零库本地切换、单曲歌单直接播放与多曲歌单正常进入。
- `npm run test:wall`：五类本地墙面、搜索展开与恢复、目录／栏目／集合及历史位置稳定、左右空态、账号头像代理、喜欢归属和三平台限制。
- `npm run test:video:surface`：原生屏幕合成首帧、两条全屏路径及自动／手动画中画退出策略。
- `npm run test:media`：视频与音乐连续性及无标题栏画中画，详见视频说明。

Electron 回归使用临时媒体库和独立数据目录。在线提交测试通过真实适配器和 IPC，搜索响应由测试桩提供，不代表真实账号、地区网络或会员能力已验收。通过 `KALEID_COMIC_EXE` 可指定 Windows 目录测试包。真实多显示器拖放、混合 DPI 跨屏和全部系统缩放组合仍需实际设备验证。

2026-10-22 的交互回归运行于 Windows 双屏桌面，两块屏幕均为 2560×1440 DIP、150% 缩放；显示器信息记录在 `artifacts/interaction-displays.json`。已覆盖此配置下的小窗拖动、四角缩放、尺寸恢复、全屏和最小化播放，未完成跨屏拖放及混合 DPI 的实机验收。
