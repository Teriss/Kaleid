# 视频播放

视频在 Kaleid 主窗口内由随包 mpv 播放。React 控制条、选集和设置侧栏与原生画面分区显示；播放器不依赖用户安装其他软件或 Windows 编解码扩展。

## 开发与打包

Windows x64，需要 Node.js 24、.NET 10 SDK 和系统 `curl.exe`。`npm ci` 后，`npm run dev` 和 `npm run build` 会先执行 `npm run video:prepare`：

- 根据 `scripts/video-runtime.json` 下载固定的非 v3 x64 mpv 发行包和 FFprobe Windows 包，校验归档 SHA-256。下载分块可重用，缓存位于 `artifacts/video-downloads/`。
- 保留原始发行包内容，将自包含 Win32 宿主编译到 `artifacts/video-runtime/host/`。用户运行安装版时不需要 .NET。
- 安装包通过 `extraResources` 将全部组件放入 `resources/video-runtime/`；开发版使用同一份已准备的组件。

不要将运行时二进制、宿主 bin/obj 或测试媒体提交到仓库。更新组件时，修改固定发行版、asset ID、文件大小和 SHA-256，重新运行准备及真实播放验收。源码归档包含宿主源码、准备脚本及版本清单。

## 文件与媒体库

识别 MP4、WebM、MKV、MOV、M4V、AVI、WMV、ASF、FLV、F4V、MPG、MPEG、TS、M2TS、MTS、VOB、RM、RMVB、3GP、3G2、OGV。文件扩展名仅用于收录，能否播放取决于内部编码和文件完整性。

启动时沿用现有后台扫描，自动发现新增格式。视频先入库，最多两个后台任务使用 FFprobe 和 FFmpeg 提取信息及封面；失败保留条目，不阻塞其他文件。缓存按文件大小、修改时间和变更时间失效，旧条目的收藏、身份和进度保留；原文件内容被替换时清除旧进度。失败任务在文件改变或手动扫描时重试。

## 使用与默认值

- 再次打开自动续播，并短暂显示“从头播放”；正常结束的文件下次从零开始。导航历史恢复为暂停。
- 选集包含同一目录全部已索引、在线的视频，采用打开时排序，不限当前加载分页。自动连播默认关闭；开启后下一集从零开始，到列表末尾停止。
- 同目录同名或带 `.语言` / `_语言` 后缀的 SRT、ASS、SSA、VTT 自动加载。其他字幕通过文件选择器添加。ASS 原有样式保留。
- 空格暂停；左右键跳转 5 秒；Shift + 左右键跳转 30 秒；上下键调音量；M 静音；F / 双击全屏。Esc 先关闭侧栏，再退出全屏，最后返回媒体库。
- 视频开始播放时暂停音乐，退出不自动恢复音乐。播放时阻止显示器休眠，暂停、结束、失败和关闭时释放。
- 后退侧键直接关闭整个视频页，包括全屏和侧栏；前进侧键沿用应用历史。原生画面和 React 控制区统一导航，过期会话的输入不生效。

## 截取片段

控制条的剪刀按钮打开截取面板并暂停。起止时间支持毫秒输入、当前位置标记和滑块，提供片段循环预览；关闭面板清除循环并暂停。默认取当前位置之后十秒，末尾按实际时长截断。

MP4 精确解码后使用 H.264（CRF 23）和选中音轨的 AAC 编码，保持源分辨率及文件自身的画面方向。可以关闭音频；源文件没有音轨时输出静音视频。HDR 转为 SDR BT.709。GIF 分两遍流式生成调色板和编码，默认宽度 480、15fps，无声音、循环播放，保留比例且不放大源视频。播放倍速、显示比例、手动旋转、字幕及超分不写入导出。

保存对话框授权输出文件。禁止覆盖源视频及其硬链接；目标文件若在导出期间发生变化则保留新文件并报告冲突。导出使用目标目录中的临时文件，成功后原子提交，失败或取消时清除；启动时清理清单中的异常退出遗留临时文件。

任务串行执行，退出视频页后继续处理。在视频页顶部或媒体库的“导出任务”入口查看进度、取消或显示完成文件。任务列表保留到应用退出；任务不跨应用重启续跑。存在未完成任务时，关闭应用提供继续等待或取消任务并退出。

## 实时超分

播放设置提供关闭（默认）、自动、通用超分和 NVIDIA RTX。通用方案是随包 FSRCNNX 1.1 的 `FSRCNNX_x2_8-0-4-1.glsl`，直接在 mpv GPU 渲染链执行，无额外推理运行时。原始着色器仅在宽高均需放大超过 1.3 倍时运行，最多执行一轮 2×；RTX 根据实际显示尺寸在 1–2× 内处理。窗口尺寸按物理像素计算，字幕和控制界面不参与超分。首版对 HDR 绕过处理并说明原因。

自动模式优先尝试活动 RTX GPU 的 D3D11 视频处理接口，接口失败则回退通用着色器。接口成功不等于驱动已实际增强，界面明确提示 NVIDIA 驱动设置依赖。非 RTX 显卡选择通用方案。检测到着色器失败时恢复普通播放；自动模式在稳定播放后连续三个五秒窗口掉帧率超过 5% 时依次降级，暂停、跳转及加载阶段不参与采样。降级在当前播放会话中保留，重新选择模式可以重试。

着色器源码位于 `scripts/video-shaders/`，来源和 SHA-256 固定在运行时清单；开发和安装版本使用同一份校验后的资源。

## 实现边界

`window.video` 只暴露受限的播放操作，主进程通过媒体 ID 验证文件；不接受任意路径或任意 mpv 命令。视频会话 ID 隔离过期事件。主进程管理宿主、命名管道、mpv 生命周期和有序进度保存，utility process 管理索引、元数据及封面。宿主在控制管道断开或父进程消失时自行退出。

本轮不包含美颜、空间裁切、多片段拼接、悬浮小窗、截图、逐帧、独立 A-B 循环工具、HDR 输出专项、投屏、光盘菜单或在线字幕下载。

## 验证

`npm run test:video`（Node 24 的实验性 TypeScript transform）检查偏好、续播、字幕、时间范围、真实 MP4/GIF 编码、音轨选择、HDR 转换、取消、文件替换及超分回退。生产构建后，使用安装的 Playwright 执行 `node scripts/test-video-playback.mjs`，或通过 `KALEID_PLAYWRIGHT_MODULE` 指定其 `index.mjs` 的绝对 file URL。

集成测试在独立临时数据目录生成真实编码样本，覆盖 100%／150%／200% 缩放、跨分页选集和播放器控制。`KALEID_VIDEO_EXE` 可指定安装版 exe，`KALEID_VIDEO_SCALES` 可缩小缩放测试范围。网页截图不包含原生 HWND；原生画面需使用 Windows 窗口截图另行检查。多显示器的跨屏行为需要真实多屏设备验收。

`node scripts/benchmark-video.mjs` 使用隔离数据和生成的 1080p H.264 片段循环播放十分钟，确认 FSRCNNX 的实际 GPU pass 并记录掉帧。默认 30fps，`KALEID_VIDEO_BENCH_FPS=24` 可测试 24fps；结果写入 `artifacts/video-sr-benchmark/`。设置 `KALEID_VIDEO_EXE` 可测打包后的程序。该脚本不会读取用户媒体库，循环样本不替代完整长片或所有显卡的验收。
