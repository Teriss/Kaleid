# 在线轻小说

小说页现在使用综合首页，提供小说源、最近阅读、本地小说、书架、稍后阅读、追更和已下载入口。本地 TXT／EPUB 仍从本地库打开。在线结果支持标准网格、立体书架和封面流；搜索可以聚合两个源或指定单源，部分源失败时保留其他源的结果并提供单源重试。

首页、抽屉菜单、封面卡片、搜索面板、详情骨架和源管理沿用漫画的展示形式。漫画与小说共用搜索面板、显隐控制、分页加载及结果布局；单源页面固定当前源，有结果时面板默认收起，通过顶部边缘或 Ctrl／Command+F 呼出。首页分区支持折叠，源支持排序与启停；小说的折叠、排序、搜索历史和聚合源选择独立保存。详情目录保留原站分卷顺序，阅读返回后恢复到章节位置；聚合结果返回时恢复到作品卡片。

未提交或清空搜索时只显示搜索表单与历史，输入文字不会自动搜索，发现页数据和全局书架布局不会出现在搜索页。搜索页隐藏全局“显示方式”，有查询的单源结果在搜索面板独立选择布局。回归检查：`node scripts/check-reading-search-empty-app.mjs`。

## 外置小说源

小说源以单个 JavaScript 文件运行，漫画源仍使用原有 Venera JS 源格式和仓库导入流程。小说源管理支持本地 `.js` 文件、远程 JS 地址，以及列出多个 JS 文件地址的 JSON 仓库索引；导入仓库时先预览来源，再选择要安装的脚本。JSON 只负责列出脚本地址和展示元数据，搜索、发现、详情、正文、登录和节点规则都在 JS 中实现。导入的脚本在受限 QuickJS 环境执行，通过 `NovelSource` 与 `host` 接口访问网络、页面解析、浏览器、SignalR、摘要和压缩能力；不能直接访问 Node.js、Electron 或文件系统。

本工作区额外生成、可手动导入的本地小说源文件位于 `local-sources/novels/importable/`。应用首次运行不自动安装来源：

- **轻书架**（`lightnovelshelf.js`）：使用 SignalR、MessagePack 和 gzip；支持游客最近更新、搜索、详情、阅读、邮箱密码登录、香港／Cloudflare API 节点切换及源站原生 EPUB 下载。登录按官方前端规则提交 UTF-8 SHA-256 小写十六进制摘要，Token 与 RefreshToken 使用 Electron safeStorage 加密保存。
- **哔哩轻小说**（`bilinovel.js`）：解析公开列表、作品、分卷目录和正文，合并站点分页；站内搜索在独立沙箱窗口中提交站点自身的搜索控件。网页登录与验证窗口共享该源的持久会话。

两个附带脚本使用稳定来源标识 `lightnovelshelf` 和 `bilinovel`。其他脚本可声明自己的来源标识和设置项；管理页根据脚本元数据生成设置与登录操作。远程安装的 JS 按来源地址或脚本声明的 `updateUrl` 检查更新。卸载脚本会清理来源运行数据和会话，但保留书架、阅读进度及已下载章节。源脚本应遵守其作者和服务提供方的版权、许可证及访问条款。哔哩遇到站点验证时需用户自行完成，后台不会自动绕过验证；登录、权限、验证、限流、网络和解析失败分别提示。

来源脚本接口与 JSON 索引格式见 [小说源开发说明](novel-source-api.md)。同名作品不跨源合并；轻书架按原站书籍／分卷 ID 保存，哔哩按作品和章节 ID 保存。不支持 Legado JSON，也不把源站收藏或跨设备进度同步到应用。

## 阅读与离线

章节正文清理后打包为 EPUB，保留段落、插图、注音、脚注锚点及源站要求的字体。阅读只加载当前章节，不先下载整本；复用本地 EPUB 阅读器的外观、翻页、滚动和文字选择。全书目录按卷分组。在线与本地阅读共用沉浸界面，点击正文中央打开底部菜单；菜单直接显示连续滚动／分页翻页、目录、书签和数值进度跳转，不再显示顶部工具栏或进度拖动条。普通阅读仅右下角显示小进度文字，在线显示当前章／总章数与章内进度。本章末尾继续向前阅读会自动切换下一章，章首反向阅读进入上一章末尾；切章加载失败保留当前章并提供重试。需要专用字体的章节优先保留源字体，避免字形显示错误。

进度、书签及继续阅读位置由 Kaleid 按源、作品和稳定章节 ID 保存。章内记录 CFI、文本偏移和阅读比例；可识别的源站更新时间变化会使临时章节缓存失效，内容版本变化时丢弃旧 CFI 并尝试按文本偏移恢复。已下载的完整章节保留下载时的快照；要更新下载请删除该章节下载后重新下载。

书架、稍后阅读和追更不依赖源站收藏。首次追更建立当前目录基线，手动“检查更新”标记新增章节，打开对应章节后清除该章的新章节标记。无后台定时检查。

下载支持当前章、选择章节、整卷、全书和未读章节。全局最多同时处理两章，每源同时处理一章。正文、全部插图及必要字体完整打包并校验后才标记完成；插图缺失会使任务失败，支持重试。任务支持暂停、继续、取消和删除；重启后未完成任务保持暂停。下载控件只区分“未下载”和“已下载”（章节进入队列即视为已下载）。“已下载”页面只展示离线作品卡片，卡片直接进入阅读；顶部“下载中”按钮打开队列弹窗，弹窗汇总下载中／排队／已暂停的作品，可暂停、继续或取消；暂停后任务仍留在弹窗内。卡片右键菜单按类型提供详情、复制标题、加入书架、稍后阅读、追更、下载，以及已下载／本地内容的打开文件夹和删除。在线和离线阅读共用进度和书签。下载只按章节上报状态变化（开始／完成／失败），渲染层会合并连续事件，故发现／搜索／阅读页不会因下载而重新加载。停用源仍能阅读完整下载；删除下载会一并清掉最近阅读、历史记录和稍后阅读条目，保留书架、追更、阅读进度与书签，且不再二次确认。

数据保存在用户目录的 `novel-online/library.sqlite`，临时章节位于 `novel-online/cache`，默认下载位置为 `novel-online/downloads`，离线 EPUB 按 `<源名>/<小说名>/<章节名>.epub` 存放，重名时自动追加序号；旧版本的 `<哈希>.epub` 会在启动时自动迁入该结构。删除最后一章后，空的小说目录与源目录会一并清理。修改下载位置只影响新建任务。下载包与临时缓存独立；损坏或缺失的下载会报告失败，不将不完整内容视为已下载。

轻书架“源站原生 EPUB”是独立的文件下载操作，受源站权限与金币规则约束。先取得费用，逐次确认后选择保存位置，下载前再次核对权限、费用和报价有效期；一个报价只能执行一次。取消或报价失效不发出下载请求。普通阅读、章节离线和预取不调用该扣费接口。原生 EPUB 不自动替换在线作品或其进度。

## 验证记录

同一小说的并发详情请求共用一次源站访问，覆盖首次同时打开目录与阅读页、并发刷新等情况；读取已保存详情不会因进入阅读器再次请求目录。失败后释放并发状态，允许重试；已有目录仍可在刷新失败时使用。专项回归：`node scripts/check-novel-requests-app.mjs`。

```powershell
npm run test:novels
npm run build
npm run test:novels:app
npm run test:reading:search
npm run test:novels:covers
npx playwright test tests/e2e/reader.spec.ts
npm run audit:novels:sources
```

`test:novels:app` 使用隔离用户目录和固定响应，覆盖真实 Electron IPC、SignalR／MessagePack／gzip、封面协议、阅读器、聚合搜索部分失败、加密凭据、追更、书签、下载队列和断网重启；截图保存在 `artifacts/novel-verification`。固定响应验证宿主逻辑，不代表真实站点全功能可用。界面回归另覆盖漫画／小说共享样式对照、首页分区不重叠、折叠记忆、源排序与启停、源管理、抽屉键盘操作、单源搜索面板、返回卡片及章节焦点，以及深浅主题和窄窗口截图。

阅读回归还覆盖跨卷自动切章、反向进入上一章末尾、定位后立即滚轮、切换阅读方式保持位置、大幅滚轮连发、切章失败保留当前章及重试。窗口重排保留待处理滚轮输入；新章节进入后等待滚轮停顿，防止惯性连续跨章。封面缓存校验会实际解码图片，截断图片按缓存未命中重新获取。

真实游客访问结果见 [分阶段验收数据](novel-source-verification.json)：轻书架公开最近更新返回六本作品，搜索需要登录，详情阶段受账号权限或站点限流影响；哔哩当前环境遇到 Cloudflare 验证。没有提供真实账号，账号权限、真实正文／插图和实际金币下载未标记通过。记录不包含 Token、密码或小说正文。

本轮本地 TXT／EPUB 已回归阅读主题、分页／滚动、文字选择、书签、数值进度跳转、快速重开和续读，10 项通过。新的底部菜单跟随阅读主题，原有正文与菜单标题同色的主题断言已通过。另有 4 项依赖 `READER_PERF_EPUB` 外部大型 EPUB 样本的性能／图片／边界测试因未提供样本而跳过。

`test:novels:covers` 使用真实轻书架公开列表，在独立 Electron Session 中验证 `media://novel` 的图片响应及图片解码。图片请求使用当前官方前端 Referer，修复旧入口 Referer 导致 Chromium `ERR_BLOCKED_BY_CLIENT` 的问题。结果和真实封面截图写入 `artifacts/novel-verification/live-covers.*`；不读取真实账号凭据。此验证不代表账号权限、正文或付费下载已通过。
