# 0.4.0-preview.3 导航与布局重构

基准仍为 Folia `26c57f9b1b26b402a09e8943171a332215418ce6`。没有启动独立 Folia 主进程或替换映间的媒体索引。高级音乐移植未完成项见 music-port-status.md。

## 已接入行为

- 墙面内容导航使用中央开口，按格块边界分开两侧卡片。导航随世界坐标移动；手动隐藏或离开视口后显示边缘标签，召回会停止惯性并在当前视口重新打开。锚点及隐藏状态按浏览范围保存。
- 四个方向的主菜单及非墙面顶部内容导航支持离开后 800ms 自动隐藏、触边唤出、键盘焦点与固定显示。隐藏控件 inert，不遮挡内容；窗口控制保留。
- `spatial` 布局的显示名称为 Folia 网格。库列表、纯目录和集合入口使用横向阵列，集合／平铺查询使用二维错列视口；歌手提供真实资料及上游 ArtistPicture；探索页使用实际可用推荐分区及当前平台最近播放。没有推荐数据的普通媒体不产生音乐栏目。
- 六种布局中的集合卡片单击进入；普通媒体维持聚焦／打开规则。无多选与文件拖出。视频缩略图在普通及聚焦时均完整显示，不自动播放。
- 墙面格位保留实际 React 卡片，只有内容层转动，150ms 转出、210ms 转入，在侧立时交换数据；调度来自上游 planFlip。来源切换使用上游 planWallWave 的反向出场与正向入场。墙面不再创建旧视口 DOM 快照。
- 非墙面层级转场使用暂存的出场画面，等待可见分页就绪再交接。Folia 网格复用 morphFlight、morphFlyIn、morphScatter 的运动计算；标准网格、列表、画廊、书架分别采用封面连续过渡、行位移、分组淡入及轻微抬起。减少动态效果关闭三维及错峰。
- 五类媒体各自维护会话历史。类型切换不记录跨类型条目；空持久化查询不会重复生成页面。导航浮层有顺序栈；Esc 依次关闭最上层、取消卡片聚焦、当前类型后退。恢复历史不执行播放命令。
- 音乐快捷面板包含播放、音效、外观三个页签，与已有音频链路和设置共用状态。主页返回库根目录；当前歌曲定位解析实际父目录，等待定位分页后聚焦，在线歌曲返回来源或搜索。播放来源保存于会话，自动切歌保留来源。
- 歌词详情打开时收起队列；队列可以独立关闭。清空队列停止并释放当前音频、清除歌词／进度／队列和播放浮层，使未完成切歌与请求失效，持久化空会话。

当前实现保留在应用源码中。构建生成的安装包、回归数据和演示素材按本地需要生成，不作为源码文档的一部分。
