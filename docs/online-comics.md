# 在线漫画与离线下载

漫画模式首页按区域展示漫画源、最近阅读、稍后阅读、本地漫画和追更；最近阅读、本地漫画、稍后阅读、追更都可以折叠，状态会保存在本机。首页本地漫画预览来自已索引的全部本地作品，不要求先读过。在线作品也能加入 Kaleid 本地收藏；收藏、稍后阅读和追更由 Kaleid 管理，不依赖源站账号的收藏功能。

## 漫画源

首页“漫画源”区域是漫画源管理的唯一入口。点击管理漫画源进入独立页面，再点“添加漫画源”打开导入弹窗。仓库列表将源标记为已导入、已勾选或未勾选；未安装源默认全选，可筛选、全选／取消选择并批量导入，失败项可单独重试。支持仓库索引、单个脚本链接和本地脚本导入，也支持 GitHub `blob`／`raw` 链接及原始文件地址。下载、解析、初始化和兼容性错误会分别报告；更新会先验证候选脚本，失败时保留现有可用版本。

管理页集中提供每个源的设置和登录。账号入口按源声明的能力提供用户名密码、Cookie 或网页登录。网页登录与该源的接口、封面和正文请求共享持久会话；不同源之间隔离。账号凭据与源设置按源保存，敏感内容使用系统加密，不进入导航记录。Cloudflare 或其他验证页面需要在网页登录流程中自行完成。源脚本来自上游仓库，按需安装且不随安装包分发。

## 发现、分类与搜索

首页漫画源标签可直接打开对应源。发现与分类先横向选择源，再显示该源提供的探索栏目、分类或排行；选择分类后进入该源的分类结果。单源搜索和分类结果保留源声明的搜索选项。

搜索可以选择聚合或单源模式。第一次聚合搜索默认包含全部已启用源；随后会记住来源选择。搜索条件和结果设置位于悬浮面板中，鼠标移至窗口上沿或按 Ctrl+F 显示，点击结果区域或开始拖动布局时收起。聚合结果只展示有内容的源，按源分组预览，点击某一组可进入该源的完整结果页。没有结果的源不显示空组；部分请求失败会列出源名、错误和单独重试入口；所有源成功但无结果时显示“未找到漫画”，全部请求失败时显示搜索失败。每个单源结果页独立记忆布局，默认标准网格，也可选立体书架或封面流；搜索结果布局不提供无限循环。结果加载可选分页或瀑布流，分页可跳到指定页；游标分页源通过顺序读取游标到达目标页，无法访问时显示实际可到达页数。瀑布流滚动至列表末尾附近时自动追加下一页。

## 作品、收藏与阅读

作品详情提供章节、继续阅读、本地收藏、稍后阅读、追更和下载操作；源未声明的能力不会显示。在线作品、本地作品均可加入 Kaleid 本地收藏。阅读历史、收藏、稍后阅读、追更和已下载有各自入口。

阅读器复用单页、双页和纵向条漫模式、书签、缩放、偏好与阅读进度。标题按章节来源标识显示“在线漫画”或“本地漫画”。章节内容与作品详情分开加载，详情请求失败时仍可保留在线章节身份；错误会显示失败阶段和具体原因，且可重新加载。源返回 HTTP 210 时显示源的等待／限流提示并允许手动重试；应用不会覆盖源脚本自身的请求语义。在线作品与已下载内容共用阅读进度，已完整下载章节可脱离源和网络续读。评论、回复、评分及源站收藏本期不展示。

## 下载

详情页支持下载当前章、选定章节、全部章节和未读章节。“已下载”管理离线内容与队列；可以暂停、继续、取消、失败重试和删除。相同章节不会重复排队。默认并行处理两个章节，每源最多两个后台图片请求，阅读请求优先。

默认保存到应用数据目录的 `comic-online/downloads`。漫画源管理页可选择新下载位置，仅影响此后创建的任务；已有任务继续使用原位置。阅读与下载共用图片请求和处理管线，下载保存处理完成、可直接离线显示的页面。重新启动后未完成任务处于暂停状态；继续时校验已有页面，必要时重新解析章节以取得失效链接。取消清理未完成章节，已完成章节保留。删除文件失败时保留任务及错误信息，可重试删除。

卸载源保留下载、书架、章节快照、收藏及进度；重新安装相同标识的源会恢复相应作品身份。删除下载不删除收藏或阅读进度。临时图片缓存与下载目录独立，清理缓存不会删除离线漫画。

## 兼容基线与诊断

运行库固定为 Venera-Next `1.18.0+234` 对应提交 `4ac4a4e68644dc51ecee5144dd9398d071692e25`（校验值见 `vendor/venera/UPSTREAM.json`），独立于 Kaleid 产品版本。源脚本在 utility process 的 QuickJS 中执行，每源独立可终止线程、上下文和 WASM 模块，受时间、内存和实例生命周期限制（CPU 片段 5 秒、操作总计 180 秒；计算／图片辅助实例最多并发 2 个、等待 8 个，禁止递归创建辅助实例）。宿主提供网络、Cookie、HTML、编码／加密、存储、设置、计时、compute、图片处理及登录界面桥接。默认请求头使用固定版 Venera-Next 的桌面 Chrome 119 User-Agent（源脚本显式设置的 User-Agent 优先），保留脚本其余请求头和额外参数；每个源的网络与 Cookie 使用独立 Electron Session，并遵循系统代理和操作系统 DNS。`http_client: dart:io` 在系统直连时使用 Node 原生请求通道并与该源 Session 同步 Cookie；系统代理路由仍通过 Electron Session 发出。上游全局自定义 DNS 覆盖不属于 Electron Session 可直接配置的接口。HTTP 状态和响应正文交回源脚本处理；源声明的 `cache-time` 与并发控制头由宿主解释。原脚本及下载地址、版本、SHA-256 持久保存，更新先验证新实例，失败保留旧脚本。

33 个脚本的基线在 `scripts/comic-sources-baseline.json`；逐源、逐阶段的真实访问结果见 [验收数据](comic-source-verification.json)。`passed` 只表示相应阶段完成，不能把解析通过或返回空列表视为全功能通过。没有账号的功能不标为实测通过。本轮实际 Electron Session 审计对 33/33 个固定脚本完成安装；17 个源取得并解码了公开首章图片，2 个源因 403 被站点拒绝，2 个源要求账号，6 个源遇到网络／超时，3 个源的图片网关返回 5xx，2 个源遇到源接口／解析错误，1 个源返回 HTML 而不是预期数据。包子漫画的 `webmota.com` 镜像能返回 108 部作品并加载详情，但章节列表仍被站点以 403 拒绝；当前实测不能据此认定是登录问题。报告区分这些结果并保留失败阶段；真实源站结果会随网络、账号和上游脚本变化。应用采用终止独立源线程的方式释放完整运行环境，本轮没有源线程释放告警。登录、认证图片、下载和离线行为另由本地响应样本进行应用测试。

- `漫画源尚未安装／已停用`：从首页漫画源区域进入管理页并安装或启用；完整下载仍可离线阅读。
- `ERR_NAME_NOT_RESOLVED`：检查当前源返回的 API 域名及 DNS／网络；若已有作品上下文，阅读页面会保留在线标题并显示具体失败阶段。
- HTTP 210：通常表示源站等待或限流；按源站提示等待后重新加载。HTTP 401 表示未授权，可检查该源登录状态。HTTP 403 代表站点拒绝访问，可能是域名／地区策略或站点验证，不能仅凭此状态判断必须登录；Kaleid 不自动绕过挑战页。可检查该源自带的域名／镜像选项，或稍后重试。
- 超时、`fetch failed`：检查网络或源设置中的域名、自建服务地址。
- 返回 HTML 却按 JSON 解析：通常为站点拦截页或上游接口变化；结合错误中的源与请求阶段诊断。
- 未实现宿主接口、脚本异常：属于兼容层或源脚本问题；保留源名称、版本、内容摘要与失败步骤用于排查。
- 下载文件损坏、磁盘错误：恢复磁盘访问后重试；删除失败时记录保留。

## 验证命令

```powershell
npm run test:comic:online
npm run build
npm run test:comic:online:app
npm run audit:comic:sources
npm run audit:comic:sources -- --live
npm run audit:comic:sources:app
node scripts/merge-comic-source-report.mjs
npm run test:comic
npm run test:comic:reader
npm run test:navigation
```

源审计保存响应阶段、错误和处理后首张图片格式／大小，不展示图片内容。默认复用下载到 `artifacts/comic-source-audit/` 的原始源快照；基线记录可比对实际脚本哈希。使用 `--only=文件.js` 可单独诊断，报告单独写入，不覆盖全源报告。设置 `KALEID_TEST_EXECUTABLE` 为打包后的 Kaleid.exe，可运行相同在线应用测试；所有应用测试使用独立临时用户目录。

上游许可与改动边界见 `vendor/venera/ADAPTATIONS.md` 和 `THIRD_PARTY_NOTICES.md`。源脚本由用户从仓库另行安装。
