# Kaleid

Windows 多媒体浏览器，支持图片、音乐、视频、小说和漫画。当前版本为 **0.4.0-preview.5**。为确保升级兼容，应用 ID、用户数据目录和音乐登录分区继续沿用旧版。音乐服务、歌词渲染和音效移植自 Folia 固定提交 `26c57f9b1b26b402a09e8943171a332215418ce6`；完整移植尚未完成，逐项状态见 [音乐移植说明](docs/music-port-status.md)。

## 运行与打包

需要 Node.js 24 或兼容的新版本、.NET 10 SDK 及 Windows x64。视频宿主以自包含方式打包，安装版无需另外安装 .NET。

```powershell
npm ci
npm run dev
```

如果安装策略跳过 Electron 下载，执行 `node node_modules/electron/install.js`；Spotify 原生模块需执行其 `scripts/postinstall.js` 下载对应 Windows 预编译文件。

```powershell
npm run build        # 类型检查及生产构建
npm run preview      # 运行生产构建
npm run dist         # Windows x64 安装包和对应源码归档
```

安装包默认输出到 `release/`；构建时生成的源码归档会随安装包附带。构建产物保留在本地，不纳入版本管理。

开发和构建会自动准备固定版本的 mpv／FFprobe 及原生视频宿主，首次需要下载播放组件；也可执行 `npm run video:prepare`。组件使用 SHA-256 校验，后续复用本地缓存，详见 [视频播放说明](docs/video-playback.md)。

## 浏览

媒体库由媒体类型、名称和一个或多个来源目录组成。原文件留在原处；同类型库引用同一路径时共享索引、收藏和阅读进度。进入具体库可逐层浏览非空目录；漫画图片目录保留漫画册语义。

六种布局：墙面（有限／无限）、空间网格、标准网格、封面流、等高画廊、等宽画廊。图片和音乐默认墙面，视频默认空间网格，小说和漫画默认标准网格。同类型共用布局偏好，各目录独立保存焦点和位置。

横向集合阵列和封面流中，点击侧边卡片先居中，再点击中心卡片或按 Enter 进入；其他布局的文件夹、歌单、专辑等集合单击进入。集合内实际只有一个媒体时直接打开该媒体，单媒体的多层目录也可跳过；返回回到原列表。墙面、空间网格中的普通媒体先聚焦再打开；标准网格单击打开，画廊单击聚焦、双击或 Enter 打开。仅提供单项右键文件操作，不支持多选或拖出文件。图片查看器自动居中适配；TXT／EPUB 和漫画提供阅读设置、目录、书签和进度恢复。覆盖式查看器锁定背景列表，退出后恢复原浏览位置。

来源目录自动监听变化；后台同步静默更新变化项，手动扫描显示进度。离线或无权限来源不视为删除。类型页签恢复最近浏览页，无历史时单库直接进入、多库显示当前类型的库列表。前进／后退仅涵盖目录、栏目、集合、媒体详情及独立搜索结果；排序、布局、过滤、浮层和视频展示方式不进入历史，也不清空前进记录。恢复历史沿用当前显示偏好，不触发播放。

五类媒体墙面使用中央菜单，本地首次进入隐藏，在线音乐显示紧凑菜单；目录、集合及历史切换保持菜单和相机位置，卡片原地翻转。搜索自动展开，可即时过滤已加载卡片或提交搜索当前库／在线平台。本地与在线保留独立切换和界面；本地菜单不显示在线栏目和账号区，未登录的在线页面仍保留中央菜单。音乐仅启用网易云、QQ 和 YouTube Music，头像打开账号面板，选择后点击“使用此平台”切换；“我喜欢的音乐”进入当前账号喜欢歌单或本地音乐收藏。头像经受控代理加载并提供失败回退。其他布局保留原导航。详见[导航与音乐墙面说明](docs/navigation-and-music-wall.md)。

角落的圆形音乐封面入口、详情、墙面、桌面歌词和迷你窗口控制同一个音频输出。封面入口悬停展开基本控制，点击打开快捷设置。支持完整范围队列、本地歌单、歌词、14 种上游歌词样式、均衡器、附加音效、响度统一、睡眠定时和输出设备；看图和阅读不打断音乐，音乐与视频主动播放时互相暂停。视频默认离开播放页时停止并保存；设置中可开启自动画中画，手动画中画可继续跨库播放。AI 主题使用用户配置的服务和加密密钥。双音轨无缝／淡化、自动混音、模型推理、外部 Now Playing 和 Folium 仍在移植中。

## 实现与数据

- Electron、React、TypeScript、electron-vite、Zustand；SQLite 扫描和缩略图处理在独立 utility process 中执行。
- `src/main/`：窗口、受限 IPC、平台后台桥接、资源协议；其中 `worker.ts` 负责本地索引与扫描。
- `src/shared/`：接口及统一导航；`src/renderer/src/`：界面、六种布局、查看器和音乐适配层。
- `vendor/folia/`：固定上游源码、许可与改动说明；不启动其整套应用主进程。
- Electron userData 中保存 `library.sqlite`、`cache/` 及 `music/`。迁移前将原数据库一致性备份到 `backups/`；播放会话重启恢复为暂停。
- 渲染器启用沙箱和上下文隔离，禁用 Node；文件通过稳定标识读取。平台和资源请求在后台执行，凭据不进入导航历史。

## 边界与许可

视频由内置 mpv 解码，支持 MKV、MP4、MOV、AVI、RMVB、TS 等常见格式，以及字幕／音轨切换、续播、选集、可选连播、MP4／GIF 片段导出及实时超分。超分默认关闭，提供跨显卡的 FSRCNNX 和 NVIDIA RTX 接口；实际兼容性取决于编码、显卡与驱动，详见[视频播放说明](docs/video-playback.md)。漫画支持图片目录、CBZ/ZIP、CBR/RAR 和 7z/CB7，包含长图续读、双页、缩放、书签、作品整理与连续翻章，详见[漫画阅读说明](docs/comic-reader.md)。不支持 DRM EPUB 或 PDF，漫画暂不支持加密／分卷包和在线来源。安装包未签名，macOS／Linux 未验收。固定音乐依赖仍有审计项，详见移植说明。

本项目包含 Folia 的 AGPL-3.0 源码，并按该许可提供对应源码。来源及其他依赖声明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)、[LICENSE](LICENSE) 和 [适配说明](vendor/folia/ADAPTATIONS.md)。

墙面的内容导航位于中央开口，可手动收起，或随墙面拖出视口；边缘标签会在当前位置召回它。其他布局使用顶部内容导航。主菜单离开后 800ms 自动隐藏，触边唤出；设置中可以固定显示。

空间网格按页面切换横向集合阵列、二维错列卡片、歌手资料和探索分区。五类媒体分别维护会话内的前进／后退历史；Esc 先关闭浮层、收起聚焦卡片，再在当前类型内后退。右下角音乐快捷设置提供播放、音效、外观、库根目录和精确歌曲定位。

等高画廊为单行等高、按真实比例展开的横向虚拟列表；等宽画廊为单列等宽、按真实比例展开的垂直虚拟列表。两种画廊仅供图片使用，其余媒体提供墙面、空间网格、标准网格和封面流。标准网格中的五类媒体均单击打开，右键操作独立。列表布局已移除，旧偏好迁移至标准网格。封面流是独立的中央放大横向布局。五类媒体墙面统一使用中央开口导航。

音乐不保存逐曲或会话播放进度，重新选择歌曲从零开始；重启仅恢复队列、当前歌曲及偏好，保持暂停且进度归零。同一首歌暂停／继续和手动跳转仍正常使用，阅读和视频进度不受影响。

墙面已按固定版本 Folia 重构世界层、滚轮运动、目录翻面和中央导航等级；五类媒体统一使用中央菜单，空态保持原布局。实现与记忆迁移见 [墙面重构说明](docs/wall-engine.md)。早期 UI 重构记录见 [UI 重构说明](docs/ui-refinements.md)。
