# media-browser 视频播放器界面

在修改播放器控件、设置侧栏、剪辑面板或播放提示时，先参考 `src/renderer/src/VideoPlayer.tsx`、`src/renderer/src/video.css`、`src/renderer/src/useVideoChrome.ts` 与 `docs/video-playback.md`。沿用当前布局和行为；用户明确要求改变时，以当前要求为准。

## 视觉规范

- 使用应用的深灰基底、白色与中性灰文字、低对比细边线、柔和圆角和简洁图标。避免播放器独有的紫色强调色。
- 播放器上下控件和侧栏采用半透明深色面板与适度背景模糊，让视频仍可见，同时保证文字和图标清晰。
- 顶栏保持精简，展示返回、标题与必要文件信息、导出任务和文件位置；为系统标题栏按钮留出安全空间。
- 底部控制区与视频边缘留出间距并使用圆角面板。把细进度条置于播放操作之上；播放、音量和工具按钮保持清晰的层级。自定义 range 轨道和滑块外观时保留原生 `input[type="range"]` 的键盘操作和焦点状态。
- 队列、字幕、设置和剪辑面板使用一致的圆角表面与内边距。用清楚的分组和高辨识度的当前选中态；表单保持紧凑易读，剪辑导出按钮始终可见，面板主体可滚动。加载、错误和续播提示沿用相同色彩与表面规则。
- 小窗口下压缩间距并缩短音量条，确保控件入口可用；检查 100%、150% 和 200% 显示缩放下的裁切与边界。

## 原生视频与控件行为

- mpv 原生画面和网页控件有独立窗口层级。不要依赖网页 `z-index` 覆盖原生画面；沿用透明控件窗口与原生画面的分层方式。
- 视频保持可用区域内的最大稳定尺寸。控件显示或隐藏只改变覆盖层的透明度和交互状态，不得改变视频画面 bounds、重新计算缩放或逐帧调整尺寸，避免画面闪动。
- 调整窗口大小时用现有 `ResizeObserver` 与 `window.video.bounds` 同步原生画面。不要把显隐动画应用到原生画面尺寸。
- 播放时闲置 1.5 秒后淡出控件；鼠标移动、点击、滚轮或键盘活动应唤回并重置计时。保留屏幕上下边缘唤回行为。暂停、加载、结束、错误、面板或弹窗打开、指针悬停、焦点停留以及拖动滑块期间保持控件显示。
- 隐藏控件时将不可见区域设为 `inert`；Tab 导航能唤回控件。减少动态效果偏好下禁用淡入淡出。会话切换或结束时清理计时器与监听器，丢弃旧会话事件，防止过期输入唤醒新页面。
- 保留已有快捷键、滚轮和偏好数据语义；扩展控件时复用现有活动通知与播放器接口，除非用户要求新增能力。

## 验收要点

- 需要验证原生视频层时，使用真实 Electron 窗口截图或播放验收脚本；普通网页 DOM 截图无法显示 mpv 原生画面。
- 检查窗口与全屏下控件显隐期间视频尺寸不变、播放/暂停和面板状态正确、边缘可唤回、键盘焦点及滑块拖动不会触发隐藏。
- 回归修改涉及的进度、音量、倍速、选集、字幕、剪辑和 Esc 操作，并按仓库脚本运行适当检查。
